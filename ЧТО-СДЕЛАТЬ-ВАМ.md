# Автопостинг: что сделать вам

Программа готова и проверена в тестовом режиме. Чтобы она начала публиковать, нужны ваши входы в соцсети. За вас их сделать нельзя.

Все ключи вы вставляете сами в GitHub: «Settings → Secrets and variables → Actions → New repository secret». Я их не вижу и нигде не печатаю.

Порядок любой. Каждую сеть включаю отдельно, как только она готова.

## 1. Telegram — 5 минут

1. В Telegram откройте @BotFather → `/newbot`, имя «LetYouWow Постинг». Он пришлет ключ. Вставьте его в секрет `TG_BOT_TOKEN`.
2. Канал: если есть t.me/letyouwow, используем его. Если нет, создайте канал.
3. В канале: «Администраторы → Добавить» → нового бота, право «Публикация сообщений».

## 2. ВКонтакте — 10 минут

1. В сообществе: «Управление → Настройки → Работа с API → Ключи доступа → Создать». Галочки: сообщения, стена. Этот ключ нужен боту «WOW» на нашем сервере, а не в GitHub. Сохраните его в файл `output/local-setup-private/vk-bot.env` на Mac двумя строками: `VK_GROUP_TOKEN=ключ` и `VK_GROUP_ID=номер сообщества`. В чат его не вставляйте: сессия сайта сама перенесет файл на сервер, не открывая его.
2. Там же «Long Poll API»: включить, версия API 5.199. Типы событий: «Входящее сообщение» и «Комментарий на стене».
3. «Сообщения»: включить сообщения сообщества.
4. Для выкладки видео нужно разрешение вашего личного аккаунта. Дам ссылку, вы нажмете «Разрешить».

## 3. Instagram — 15 минут

1. Аккаунт должен быть профессиональным: «Настройки → Тип аккаунта → Автор» (или «Бизнес»).
2. Зайдите на developers.facebook.com, создайте приложение «LetYouWow Постинг», сценарий «Instagram API».
3. В разделе «Instagram API → Generate token» добавьте свой аккаунт, нажмите «Разрешить». Токен вставьте в секрет `IG_TOKEN`.

## 4. Threads — 5 минут

В том же приложении добавьте сценарий «Threads API», добавьте себя тестировщиком и получите токен. Вставьте его в секрет `THREADS_TOKEN`.

## 5. TikTok — 15 минут и ожидание проверки

1. На developers.tiktok.com создайте приложение. Добавьте продукт «Content Posting API» и включите «Direct Post».
2. Ключи «Client key» и «Client secret» вставьте в секреты `TIKTOK_CLIENT_KEY` и `TIKTOK_CLIENT_SECRET`.
3. Дам ссылку входа: вы нажмете «Авторизовать» и вставите адрес, куда вас перекинет, в программу входа. Вход сохранится в зашифрованном виде.
4. Подайте приложение на проверку («Submit for review»). Тексты для заявки я подготовлю.
5. Пока проверки нет, ролики там видны только вам. После проверки включу показ всем.

## 6. Manychat — личка в Instagram, 10 минут

1. На manychat.com войдите через Instagram и оплатите тариф Essential турецкой картой: около $14–15 в месяц.
2. Автоматизация: «комментарий со словом WOW → сообщение в личку со ссылкой». Тексты дам готовые.

## 7. GitHub и сервер — я сделаю сам, если скажете «можно»

- Открытое хранилище `letyouwow-autopost`: программа и расписание. В открытом хранилище робот работает бесплатно без ограничения по минутам. Ключи там не лежат: они в секретах, а сменяемые токены зашифрованы.
- Сами ролики лягут на наш сайт, по адресу letyouwow.ru/reels/. Оттуда их будут забирать Instagram и Threads.
- Бот ВКонтакте «WOW» должен работать круглосуточно. Он поедет на наш сервер вместе с сайтом.
- Секрет `STATE_KEY` (ключ шифрования токенов) я создам сам: длинный случайный, сразу в секреты GitHub, никому не показываю.
